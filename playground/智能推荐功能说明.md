# 智能推荐功能说明

## 功能概述

在投资代理列表页面新增了智能推荐功能，该功能可以：

- 获取用户当前地理位置
- 调用高德地图POI接口搜索附近的工厂
- 以弹窗形式展示推荐的工厂信息
- 支持选择推荐的工厂

## 配置说明

### 1. 高德地图API Key配置

在 `.env` 文件中配置您的高德地图API Key：

```env
# 高德地图API Key
VITE_AMAP_KEY=您的高德地图API_KEY
```

### 2. 获取高德地图API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册并登录账号
3. 创建应用，选择「Web服务」类型
4. 获取API Key并配置到环境变量中

## 功能特性

### 智能推荐按钮

- 位置：列表页面工具栏
- 图标：灯泡图标
- 状态：支持加载状态显示

### 智能定位

- 自动获取用户当前地理位置
- 支持高精度定位
- 优化定位参数：15秒超时，5分钟缓存
- 详细的错误提示和解决建议

### 手动地址输入（备用方案）

- 当自动定位失败时提供手动输入选项
- 支持地理编码API，将地址转换为坐标
- 智能地址识别和验证
- 用户友好的输入界面和提示

### POI搜索参数

- 搜索关键词：工厂
- 搜索半径：5000米
- 返回数量：最多20个
- 类型码：050301（商务住宅相关场所）

### 推荐弹窗

- 宽度：800px
- 显示信息：工厂名称、地址、距离、联系电话
- 支持滚动：最大高度400px
- 操作：选择工厂、关闭弹窗

## 错误处理

### 自动定位错误处理

- 浏览器不支持地理位置服务
- 用户拒绝位置权限：提供详细的权限设置指导
- 位置获取超时：优化超时时间为15秒，提供网络和GPS信号建议
- 位置服务不可用：建议检查设备定位服务
- 网络请求失败
- API Key未配置或无效

### 备用方案

- 当自动定位失败时，系统会自动提示用户选择手动输入地址
- 支持地理编码，将用户输入的地址转换为坐标进行搜索
- 提供详细的地址输入提示和格式说明

## 使用流程

### 自动定位流程

1. 用户点击「智能推荐」按钮
2. 系统请求获取用户位置权限
3. 获取当前地理位置坐标（15秒超时）
4. 调用高德地图API搜索附近工厂
5. 在弹窗中展示搜索结果
6. 用户可以选择合适的工厂
7. 关闭弹窗完成推荐流程

### 手动输入流程（定位失败时）

1. 自动定位失败后，系统提示选择手动输入
2. 用户确认后打开地址输入弹窗
3. 用户输入详细地址信息
4. 系统调用地理编码API获取坐标
5. 基于坐标搜索附近工厂
6. 展示搜索结果供用户选择

## 技术实现

### 主要技术栈

- Vue 3 Composition API
- TypeScript
- Ant Design Vue
- 高德地图Web服务API
- 浏览器Geolocation API

### 核心函数

- `getCurrentPosition()`: 获取当前位置（优化定位参数）
- `searchNearbyParks()`: 搜索附近工厂
- `onSmartRecommend()`: 智能推荐主流程
- `searchByManualAddress()`: 手动地址搜索
- `closeRecommendModal()`: 关闭推荐弹窗
- `closeManualLocationModal()`: 关闭手动输入弹窗

## 注意事项

1. **HTTPS要求**：地理位置API需要在HTTPS环境下使用
2. **用户授权**：首次使用需要用户授权位置访问
3. **API限制**：高德地图API有调用频率限制
4. **跨域问题**：可能需要配置代理或CORS
5. **隐私保护**：遵守用户隐私保护相关法规
6. **用户体验**：提供了完整的错误处理和备用方案
7. **地址格式**：手动输入时建议使用详细地址格式
